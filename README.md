shell -> Contient les données de personnalisation personnel du shell de l'utilisateur (principalement des aliases). A envoyer au path : "~/.bashrc".

gdb -> Contient les données nécessaires à la personnalisation personelle du déboggeur gdb et gef à écrire dans le document se trouvant au path : "~/.gdbinit".

git -> contient un fichier nommé "config" qui contient les préférences de partages pour git (ne contient pas les configurations globals du git).

.gitignore -> Empêche les leaks d'informations importantes/privées

nvim -> Contient un fichier nommé "init.lua" qui contient les éléments de personnalisation de base Neovim pour C.
A envoyé au path : "~/.config/nvim/init.lua"

vscode -> Contient un fichier "settings.json" qui contient les paramètres utilisateurs pour vscode.
